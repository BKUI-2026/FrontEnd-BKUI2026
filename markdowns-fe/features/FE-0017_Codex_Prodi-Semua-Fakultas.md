## Perubahan

- Semua kartu fakultas kini menampilkan chip hijau berisi nama program studi,
  mengikuti pola yang sebelumnya hanya ada di kartu Fasilkom.
- Daftar program sarjana mengacu pada Brosur Program Pendidikan UI 2025.
- Daftar Program Pendidikan Vokasi mengacu pada laman resmi Vokasi UI dan
  mencakup program diploma serta sarjana terapan.
- Program Kecerdasan Artifisial Fasilkom dipertahankan sesuai desain BKUI 2026.
- Tidak ditambahkan uraian atau detail baru per program studi.
